Colores multinavegadores

Hay mas de 100 colores con nombre, que son compatibles con la mayoria de los navegadores modernos estos nombres se pueden usar directamente en css para aplicar colores a elementos sin especificar valores de algún modelo de color.

Por ejemplo :

  • Negro
  • Blanco
  • Salmon
  • Azul
  • Verde

Border

Para que a un elemento HTML se le aplique color a su borde, se necesitan 3 propiedades: Una de ellas es border-style, otra es border-color y adicionalmente border-width
