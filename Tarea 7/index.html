Resumen de HTML

Esta página va a resumir los principales conceptos y etiquetas vistos en la clase de Programación Web I, en el módulo HTML.

Conceptos principales HTML

HTML

Lenguaje de marcado de hipertexto, es un lenguaje de marcas que se utiliza para estructurar sitios web.

Elemento HTML

Un elemento HTML es la unidad básica de estructuea y contenido en una página web, esta compuesta de:

  1. Etiqueta de apertura.
  2. Pares atributos-valor.
  3. Contendio.
  4. Etiqueta de cierre.

Etiqueta <head>

Es una etiqueta que se utiliza para comunicarse con el navegador a través de los metadatos, permite mejorar el SEO, además se enlaza archivos externos de estilos o scripts.

Etiqueta <body>

Dentro de esta etiqueta va todo del contenido que ve el usuario en nuestra página web.

Contenedores semánticos

<header> Es una etiqueta utilizada para el contenido introductorio de una página web. Puede contener el logo, el menú de navegación principal, el nombre de la empresa, etc.
<nav> Es una etiqueta utilizada para el menú de navegación principal, suele contener enlaces a otras páginas relacionadas o navegar por la página principal. No debe de haber más de una etiqueta <nav>.
<main> Es una etiqueta única de una página web, cuyo propósito es resaltar nuestro objetivo o mensaje principal del sitio web. Dentro se colocará el contenido principal de nuetsra página.
<section> Es una etiqueta que poco a poco intenta sustituir a <div>, su uso es para dividir a una página web en secciones y agrupar contenido relacionado.
<article> Es una etiqueta que se utiliza para agrupar contenido autonómo, que si se separa de otro contenido sigue teniendo coherencia. Normalmente se compone de un encabezado y contenido.
<footer> Es una etiqueta que normalmente se encuentra hasta el final de una página, y funciona como el cierre del sitio web. A menudo, contiene datos de contacto, derechos de autor u otra información complementaria.
<aside> Esta etiqueta que representa una sección de la página web, cuyo contenido no está directamente relacionado con el contenido principal del documento, como: barras laterales, publicidad, enlaces a otros artículos relacionados, etc.

Elementos principales de HTML

Elemento <a>

Este elemento contiene enlaces a otras páginas:

  • Enlaces externos
  • Enlaces internos
  • Enlaces de anclaje

Algunos valores especiales que tiene en su atributo href son:

href="https://wa.me/5574006293"
Este valor envía un WhatsApp a un número específicado
href="mailto:example@gmail.com"
Este valor envía un correo a un mail en específico

Elemento <form>

Es la forma en que los usuarios de un sitio web pueden comunicarse con el, mediante el formulario se reciben, procesan y envián datos de los usuarios para el fin u objetivo del sitio web
