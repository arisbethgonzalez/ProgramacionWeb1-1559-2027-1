Tipos de estilo en css

Estilos en linea

Estos estilos se van a agregar directamente en el elemento HTML, mediante el atributo <style>

Este parrafo tiene estilos en linea

Estilos internos

Se agregan en el mismo archivo HTML dentro del <head>, y para agregarlos se utiliza el elemento: <style>

Estilos externos

Estos estilos son los que se recomiendan usar, ya que ofrecen modularidad, facil mantenimiento, orden, eficiencia, entre otras ventajas. Para agregar una hoja de estilos externa, dentro de la etiqueta <head> se utiliza el elemento <link>, donde vamos a especificar la ruta de nuetsra hoja de estilos.
